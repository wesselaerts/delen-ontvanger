# Delen: Chromecast-ontvanger

Een kleine Chromecast-ontvanger (Custom Receiver) die het scherm van een tablet op de tv toont. De
tablet stuurt elk nieuw beeld als JPEG over de Cast-verbinding; de pagina wisselt pas als het
volledige beeld binnen is, zodat er niets flikkert.

Alleen `index.html`. Geen gegevens, geen volgcode.

De zender (`zender.html`) start de ontvanger vanuit Chrome op een tv.
